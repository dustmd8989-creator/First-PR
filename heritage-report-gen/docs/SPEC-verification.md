# 명세: 생성 본문 사후 검증과 확인 필요 항목 강조

## 배경
`prompts/_system.md`는 "메모에 없는 사실을 만들지 않는다"는 원칙을 담고 있으나,
이를 코드가 검증하지 않는다. 또한 `[확인 필요]` 표시가 docx에서 일반 글씨로 출력되어
조사자가 놓치기 쉽다.

## 요구사항
1. 생성된 절 본문에서 숫자(연대, 치수, 수량)를 추출해 조사자 메모에 없는 값을 경고한다.
   - `[확인 필요: ...]` 괄호 안의 숫자는 검사에서 제외한다.
   - 경고는 stderr에 절 제목과 함께 출력한다. 생성 자체는 중단하지 않는다.
2. docx에서 `[확인 필요...]` 구간은 노란색 형광펜으로 강조한다.
3. 보고서 끝에 "검증 요약"(절별 확인 필요 개수, 메모에 없는 숫자)을 붙이고,
   `--no-summary`로 끌 수 있다.

## 범위 밖
- 한자 숫자, 한글 수사(예: 삼 칸)의 검증
- 출전과 각주 구조화
- 의미 수준의 환각 탐지 (숫자 외 사실)

## 수용 기준
- 메모에 없는 숫자가 본문에 있으면 경고 목록에 나온다.
- 메모에 있는 숫자와 `[확인 필요]` 안의 숫자는 경고되지 않는다.
- `[확인 필요...]` 런에만 형광펜이 적용된다.
- API 없이(가짜 응답) 전체 흐름이 .docx까지 완료된다.

## 한계
숫자 일치만 확인하므로 메모의 숫자를 엉뚱한 곳에 쓰는 오류는 잡지 못한다.
